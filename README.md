# Rahul M Nair — Portfolio

A responsive, dark-themed personal portfolio built with HTML, CSS and JavaScript.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `rahullmnairr.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Your site will be published at `https://rahullmnairr.github.io/` after GitHub Pages finishes deploying.

## Personalize before publishing
- Add a portrait to `assets/` and replace the photo placeholder in `index.html` when ready.
- Add your email address to the Contact section if you want it displayed.
- Add project repository links and screenshots when available.
- Update the Skills section as your experience grows.

## Files
- `index.html` — page content
- `style.css` — responsive styling
- `script.js` — mobile navigation
- `assets/` — place images here
